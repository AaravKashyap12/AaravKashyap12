## Things I have made

<h3>advise-project-approach <sub>— a skill for better project judgment</sub></h3>

AI agents should not give project advice from vibes. This skill makes them investigate the constraints, comparable projects, costs, trade-offs, and failure conditions before recommending what to build. <a href="https://github.com/AaravKashyap12/advise-project-approach">Explore the project →</a>

<h3>Quill <sub>— voice input, with agency</sub></h3>

A local-first voice dictation app with two intentional modes: speak exactly as you mean, or pause to shape it before anything reaches your cursor. Privacy and control are not footnotes. <a href="https://github.com/AaravKashyap12/quill">Explore the project →</a>

<h3>TalentMatch <sub>— evidence over keywords</sub></h3>

An AI-assisted screening workflow that turns a role and a batch of resumes into an explainable shortlist—so hiring teams can see the reasoning behind the ranking. <a href="https://github.com/AaravKashyap12/TalentMatch">Explore the project →</a>

<h3>CryptoQuant <sub>— transparent market signals</sub></h3>

An educational forecasting dashboard that combines live market signals, locally trained models, and clear fallback baselines without pretending the future is certain. <a href="https://github.com/AaravKashyap12/CryptoQuant">Explore the project →</a>
